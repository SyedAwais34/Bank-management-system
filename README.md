# 🏦 Bank Management System

A simple Python-based Bank Management System that allows users to create accounts, deposit money, withdraw money, update account details, and delete accounts.  
All user data is stored in a JSON file for persistent storage.

---

# 🚀 Features

✅ Create Bank Account  
✅ Generate Unique Account Number  
✅ Deposit Money  
✅ Withdraw Money  
✅ View Account Details  
✅ Update User Information  
✅ Delete Account  
✅ Data Stored in JSON File  

---

# 💾 Data Storage

All account information is stored inside:

```bash
data.json
```

Example:

```json
[
  {
    "name": "Awais",
    "age": 20,
    "email": "awais@gmail.com",
    "pin": 1234,
    "accountNo.": "A1b@23",
    "balance": 5000
  }
]
```

---

# 🔐 Account Security

- Every account has:
  - Unique Account Number
  - 4-digit PIN
- PIN is required for:
  - Deposits
  - Withdrawals
  - Updating Details
  - Deleting Account
